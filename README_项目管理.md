# AetherLight Pro - 项目制管理使用指南

## 新功能说明

现在 AetherLight Pro 已经支持项目制管理,你不需要每次启动都重新导入 GDTF 和 MVR 文件了!

## 主要改进

### 1. GDTF 自动保存到数据库
- 首次导入 GDTF 文件后,会自动保存到 `gdtf_library.db` 数据库
- 重启程序时自动从数据库加载所有 GDTF
- 不同项目可以共享相同的 GDTF 库

### 2. 项目自动保存
- 每个项目保存在 `projects/` 目录下的 JSON 文件中
- 包含项目的所有 Fixture 配置和 GDTF 链接关系
- 关闭程序时自动保存当前项目

### 3. 窗口标题显示项目状态
- 显示当前项目名称
- 有未保存的更改时显示 `*` 标记
- 例如: `AetherLight Pro — 默认项目 *`

## 使用方法

### 启动程序
```bash
python main.py
```

程序会自动:
1. 从数据库加载所有 GDTF Profile
2. 加载最近使用的项目(如果有)
3. 如果没有项目,创建一个"默认项目"

### 项目菜单 (File)

#### 新建项目 (Ctrl+N)
1. 点击 `File → New Project`
2. 输入项目名称
3. 创建一个空白项目

#### 打开项目 (Ctrl+O)
1. 点击 `File → Open Project`
2. 从列表中选择项目
3. 加载项目的所有配置

#### 保存项目 (Ctrl+S)
1. 点击 `File → Save Project`
2. 或者直接关闭程序(自动保存)

### 工作流程示例

#### 首次使用
1. 启动程序
2. 导入 GDTF 文件 → 自动保存到数据库
3. 导入 MVR 文件 → 灯具自动链接
4. 关闭程序 → 自动保存项目

#### 后续使用
1. 启动程序 → 自动加载GDTF和上次项目
2. 继续工作
3. 关闭程序 → 自动保存

#### 多项目管理
1. 当前项目: 演唱会主舞台
2. 新建项目: 户外灯光秀
3. 导入不同的 MVR → 自动链接相同的 GDTF
4. 随时切换项目

## 数据文件位置

```
AI_DMX/
├── gdtf_library.db          # GDTF 数据库(全局,所有项目共享)
└── projects/                # 项目文件夹
    ├── 默认项目.json
    ├── 演唱会主舞台.json
    └── 户外灯光秀.json
```

## 注意事项

1. **GDTF 数据库是全局的**
   - 所有项目共享同一个 GDTF 数据库
   - 只需导入一次,多个项目都可以使用

2. **项目文件是独立的**
   - 每个项目有自己的 Fixture 配置
   - 可以安全地创建多个项目

3. **自动保存**
   - 关闭程序时自动保存当前项目
   - 也可以手动按 Ctrl+S 保存

4. **GDTF 分类**
   - GDTF 按 manufacturer 和 library_name 分类
   - library_name 从 GDTF 的 long_name 字段提取
   - 例如: `EpicGames / DMXL_huzhou`

## 快捷键

- `Ctrl+N` - 新建项目
- `Ctrl+O` - 打开项目
- `Ctrl+S` - 保存项目
- `Ctrl+Q` - 退出程序

## 常见问题

**Q: 我的 GDTF 文件不见了?**
A: GDTF 保存在数据库中,重启程序会自动加载。如果数据库文件 `gdtf_library.db` 被删除,需要重新导入。

**Q: 我的项目配置不见了?**
A: 项目保存在 `projects/` 目录下的 JSON 文件中。确保该目录没有被删除。

**Q: 如何备份我的配置?**
A: 备份以下文件即可:
- `gdtf_library.db` (GDTF 数据库)
- `projects/` 目录 (所有项目)

**Q: 可以同时打开多个项目吗?**
A: 当前版本一次只能打开一个项目,但可以随时切换。

**Q: 窗口标题上的 * 号是什么意思?**
A: 表示项目有未保存的更改,按 Ctrl+S 保存或关闭程序自动保存。
