# spatial.py 测试报告

## 测试概述

本测试验证了 `aetherlight/spatial.py` 模块的核心功能，包括：
1. **坐标排序功能** - 按不同轴（X/Y/Z/radial/angle）对灯具进行排序
2. **Phase 归一化计算** - 将排序后的位置归一化到 0.0~1.0 范围
3. **自动轴检测** - 根据灯具分布自动选择最佳排序轴

## 测试结果

✅ **所有测试通过！**

## 详细测试项

### 1. X/Y/Z 轴排序测试

**测试目的：** 验证按单一坐标轴排序是否正确

**测试用例：**
- X 轴排序：灯具按 X 坐标从小到大排序
- Y 轴排序：灯具按 Y 坐标从小到大排序  
- Z 轴排序：灯具按 Z 坐标从小到大排序

**验证点：**
- ✅ 排序后灯具顺序正确
- ✅ 第一个灯具 phase = 0.0
- ✅ 最后一个灯具 phase = 1.0
- ✅ Phase 值单调递增

**示例：**
```python
# X 轴排序
原始: [F3(3,0,0), F1(1,0,0), F5(5,0,0), F2(2,0,0), F4(4,0,0)]
排序: [F1(1,0,0), F2(2,0,0), F3(3,0,0), F4(4,0,0), F5(5,0,0)]
Phase: [0.0, 0.25, 0.5, 0.75, 1.0]
```

### 2. 径向排序测试（Radial）

**测试目的：** 验证从灯组中心向外的距离排序

**工作原理：**
1. 计算所有灯具的中心点 (cx, cy, cz)
2. 计算每个灯具到中心点的距离
3. 按距离从近到远排序

**验证点：**
- ✅ 最近的灯具排在前面
- ✅ 最远的灯具排在后面
- ✅ Phase 随距离单调递增

### 3. 角度排序测试（Angle）

**测试目的：** 验证按环形角度排序（适用于圆形布局）

**工作原理：**
1. 计算灯组中心点
2. 使用 `atan2(y-cy, x-cx)` 计算每个灯具的角度
3. 按角度排序（-π 到 π）

**验证点：**
- ✅ 角度排序正确
- ✅ Phase 值正确分配

### 4. 自动轴检测 - 单轴分布

**测试目的：** 验证当灯具主要沿单一轴分布时，能正确检测该轴

**检测逻辑：**
1. 计算 X/Y/Z 三个轴的方差
2. 对方差排序，取最大两个
3. 如果 `次大方差 / 最大方差 ≤ 0.5` → 单轴分布，返回方差最大的轴

**测试用例：**
- X 轴线性分布 → 检测为 "x" ✅
- Y 轴线性分布 → 检测为 "y" ✅
- Z 轴线性分布 → 检测为 "z" ✅

### 5. 自动轴检测 - 平面分布

**测试目的：** 验证当灯具在平面上散布时，能检测为 radial

**检测逻辑：**
- 如果 `次大方差 / 最大方差 > 0.5` → 平面分布（两个轴方差都较大）
- 返回 "radial"

**测试结果：**
- XY 平面分布 → 检测为 "radial" ✅
- 方差比值 > 0.5 阈值 ✅

### 6. Phase 归一化计算

**测试目的：** 验证 phase 值正确归一化到 [0.0, 1.0] 区间

**计算公式：**
```
phase[i] = (key[i] - min_key) / (max_key - min_key)
```

**验证点：**
- ✅ 第一个灯具 phase = 0.0
- ✅ 最后一个灯具 phase = 1.0
- ✅ 中间灯具 phase 按比例分配
- ✅ 所有 phase 值在 [0.0, 1.0] 范围内

### 7. Auto 模式测试

**测试目的：** 验证 `axis="auto"` 或 `axis=None` 时能正确调用自动检测

**验证点：**
- ✅ Auto 模式调用 `auto_detect_axis()`
- ✅ 返回检测到的轴名称
- ✅ 使用检测到的轴进行排序

### 8. 边界情况测试

**测试用例：**
1. **单个灯具**
   - phase = 0.0 ✅
   - 返回默认轴 ✅

2. **空列表**
   - 返回空列表 ✅
   - 返回默认轴 "x" ✅

3. **所有灯具同一位置**
   - 不报错 ✅
   - 所有 phase = 0.0 ✅
